# CodeTech Task 1 - Decision Tree Classification

## 📌 Overview
This project is submitted as part of the **CodeTech Internship (Task 1)**. 
It implements a **Decision Tree Classifier** to classify flower species using the classic **Iris Dataset**.

## 📊 Dataset
- **Name:** Iris Dataset
- **Features:** Sepal Length, Sepal Width, Petal Length, Petal Width
- **Target:** Species (Setosa, Versicolor, Virginica)
- **Source:** Built-in dataset from `sklearn.datasets`

## 🛠️ Tech Stack
- Python
- Pandas
- Scikit-learn
- Matplotlib / Seaborn (for visualization)
- Jupyter Notebook

## 🔍 Approach
1. Load and explore the Iris dataset
2. Data preprocessing and train-test split
3. Train a Decision Tree Classifier using Scikit-learn
4. Visualize the decision tree
5. Evaluate model performance (accuracy, confusion matrix)

## 📈 Results
- The Decision Tree model was trained and tested on the Iris dataset, achieving high classification accuracy in predicting flower species.
